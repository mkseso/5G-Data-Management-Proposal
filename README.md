# Data Management in the Era of 5G Technology

## Abstract

This project focuses on designing a scalable data management system for handling large-scale data generated in 5G environments. It aims to improve data processing, storage, and real-time analytics.

## Tools

* Python
* MySQL
* Apache Hadoop
* Lucidchart

## Installation

1. Install Python
2. Install MySQL
3. Install Hadoop
4. Run the project
